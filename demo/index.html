The window length is configured per contract via set_timelock_window(admin, seconds) and defaults to 172 800 s = 48 h. Valid bounds: 1 h to 30 d.

🛡️ Critical Admin Actions
propose_pause / execute_pause / cancel_pause

⏸ Pause

Stages, applies, or cancels a vault pause. Owner retains immediate pause() for parallel fast-path.

propose_upgrade / execute_upgrade / cancel_upgrade

⬆️ WASM Upgrade

Snapshots BytesN<32> hash, applies via host deployer only after window elapses.

propose_sweep / execute_sweep / cancel_sweep

💸 Sweep (Distribute)

Drains on-ledger USDC surplus to a verified recipient with a 48 h public notice.
